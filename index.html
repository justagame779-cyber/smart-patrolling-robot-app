Smart Patrolling Robot

   The primary aim of this project is to develop an autonomous security and surveillance robot engineered to patrol designated environments efficiently. Designed with a modern multi-legged spider chassis, it combines real-time thermal scanning, motion detection, autonomous path finding, and system diagnostic telemetry to deliver robust monitoring capabilities.

Thermal Imaging
Grid heat array mapping for heat signature detection.
PIR Motion
Infrared motion tracking for immediate intruder detection.
GPS Positioning
Geographic telemetry for location mapping.
Line Tracking
IR sensor guided autonomous path traversal.
Distance Measuring
Measuring obstacle infront of it's patrolling route.
Voltage Monitor
Continuous battery voltage diagnostics and power safeguard.
